# Example graphs

Knowledge graphs built with `kg` for three public projects, as part of the
MVP validation (#12, [report](../mvp-validation.md)). Each page is a single
offline HTML file: open it in a browser, search, filter by type and click a
node for its details and provenance. They are also served with GitHub Pages at
`https://cristian1a.github.io/kg/examples/<project>.html`.

| Level | Project | Graph | Nodes / edges |
|-------|---------|-------|---------------|
| Easy | [alfredodeza/basic-python-cli](https://github.com/alfredodeza/basic-python-cli) | [basic-python-cli.html](basic-python-cli.html) | 10 / 12 |
| Intermediate | [bramvdklinkenberg/my_first_data_project](https://github.com/bramvdklinkenberg/my_first_data_project) | [my_first_data_project.html](my_first_data_project.html) | 66 / 98 |
| Complex | [wesleey/python-clean-architecture](https://github.com/wesleey/python-clean-architecture) | [python-clean-architecture.html](python-clean-architecture.html) | 398 / 737 |

Each graph combines `kg extract` (code, tests, dependencies) with the
documents, decisions, concepts and issues an agent (Claude Code) added
following `kg guide`; the agent's input is in
[`examples/agent/`](../../examples/agent/).

## Regenerating

```bash
git clone https://github.com/<owner>/<repo> samples/<repo>     # at the commit above
kg init --kg-dir samples/runs/<repo>/.kg
kg extract samples/<repo> --kg-dir samples/runs/<repo>/.kg
kg add examples/agent/<repo>.json --kg-dir samples/runs/<repo>/.kg
kg render --html --kg-dir samples/runs/<repo>/.kg -o docs/examples/<repo>.html
```
