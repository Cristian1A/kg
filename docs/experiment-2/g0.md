# Experiment 2: gate G0

**Result: G0 passes.** With a memory (S2) the agent scores 0.529 more than
without one (S0) on the questions that only GitHub or a session can answer.
The pre-registered threshold was 0.15 ([requirements](requirements.md) §7).

- Run: session `20261025T212002Z`, 40 questions × S0, S2 × 3 repeats = 240
  runs, 2026-10-25 to 2026-10-26, Claude Code subagents (`claude-opus-5-5`).
- Results: `bench/results/memory/20261025T212002Z.jsonl`
  (`python -m bench.report` prints every table below).
- The keyword grader stays frozen; its known bias is discussed under
  [Caveats](#caveats).

## The gate

The 15 hidden questions are the ones whose `lives_in` contains neither `file`
nor `git-log`.

| Set | S0 | S2 | S2 − S0 |
|-----|----|----|---------|
| 15 hidden questions, all runs | 0.387 | 0.916 | **+0.529** |
| Same, without the 3 protocol violations | 0.396 | 0.916 | +0.520 |
| 25 visible questions | 0.905 | 0.980 | +0.075 |

- The question-level bootstrap gives a 95% interval of 0.32 to 0.73 for the
  difference (10,000 resamples of the 15 per-question mean differences,
  seed 71). Its lower end is still twice the threshold.
- On visible questions memory adds little, as expected: the agent can read
  the answer in the repo.

## Caveats

- **Lenient grader.** The keyword grader gives credit when an answer names
  the expected terms, even when it says it does not know (`kg-R3.s0.2` scored
  1.00 with a guess). This favours S0. The hand audit below measures it.
- **Protocol violations.** Three runs (`kg-M6.s0.3`, `kg-S2.s2.3`,
  `kg-B1.s0.3`) piped tool output through shell helpers, against the prompt.
  Removing them changes the difference by less than 0.01.
- **Corpus written after the questions.** The curated corpus was written
  knowing the questions; S2 retrieves from it. The agent-written corpus
  (R2-11) is the control, still to build. G0 says that a memory with the
  right records helps a lot. It does not say yet that an agent will write
  those records.
- **Missing usage.** One run (`kg-C5.s2.2`) has no token count in its
  transcript. Its score is unaffected.
- **Size.** 40 questions on one corpus (kg). This is enough to guide the
  next phase, not to be statistically conclusive. The Engram and pandas
  corpora come later.

## Hand audit of the hidden answers

All 90 answers to the 15 hidden questions were read by hand (2026-10-26),
next to each question's reference. The mechanical score stays the official
one; the audit only qualifies it.

| | S0 (45 runs) | S2 (45 runs) |
|---|---|---|
| No answer (25 calls used) | 6 | 0 |
| Answers that say the repo does not record the answer | 18 | 0 |
| Answers that infer "no" from missing evidence | 3 | 0 |
| Answers that find the recorded fact | 18 | 45 |

- **Abstentions:** `kg-B1.s0.3`, `kg-C4.s0.1–3`, `kg-C5.s0.3`, `kg-D8.s0.1–3`,
  `kg-M7.s0.1–3`, `kg-N4.s0.1–3`, `kg-R3.s0.1–3`, `kg-R5.s0.1`. Most of them
  add a guess or the closest thing the repo has. The grader gave them 7.0
  points in all (mean 0.39), including 1.00 to each of the three `kg-R3`
  guesses.
- **Inferred "no":** `kg-S5.s0.1–3` say there is no evidence that the CI
  template was tried. This is the right yes/no answer, but without the
  reason (it was replaced on purpose). They scored 0.
- **Effect:** scoring the 18 abstentions as 0 lowers S0 from 0.387 to
  0.231, so the difference grows from +0.529 to **+0.684**.
- **A false negative against S2:** the three `kg-B1.s2` runs name the right
  decision (commit kg's own graph and run the CI template on it). They also
  name the right condition, "when agents should query kg's graph without
  building it". But they do not name RF-23 / the MCP server, or say that it
  was never started, so they score 0. Counted as 0.5, S2 would rise to 0.949
  and the difference to +0.717. kg-B1 is therefore not a retrieval failure
  of S2, as the table above suggested. It is a partial answer the strict
  keywords miss.
- **Wrong but confident:** the S0 answers to `kg-R6` describe options taken
  from the repo (go on to step 1 or stop), not the ones the session weighed
  (option 1 against option 3, the 50% doubt). They do not abstain; they
  answer a different question from what the repo shows.
- **S2 never abstains.** Every S2 answer states the recorded fact, often
  citing the memory record. The audit found no answer where S2 invented a
  fact that is not in the corpus.

In short, the audit strengthens the result: both grader errors found work
against S2, and the corrected gap is between +0.68 and +0.72.

## What it means for P2

Memory is worth having, so the experiment goes on. The question is no longer
whether a memory helps, but whether a graph helps more than FTS5. S2 already
scores 1.00 on rationale, multi-hop and supersession, so G1 (graph +0.10 over
the best non-graph strategy) has little room there. It can be met mainly on
**blocked** (0.75) and **continuation** (0.85), and in evidence recall.
